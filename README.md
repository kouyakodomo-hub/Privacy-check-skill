# Privacy-check-skill
privacy-check は、アプリ、サービス、機能、データの扱いについて、プライバシーの観点から問題がないかを判断してくれるスキルです。  「このアプリでユーザーの位置情報を集めて大丈夫?」「友達機能を付けたいけど他人の情報の扱いは?」といった相談に対して、次の形で答えます  A Claude skill that judges whether an app, feature, or data practice is OK from a privacy standpoint. Works at the planning, implementation review, and post-launch stages.
